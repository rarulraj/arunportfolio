## Challenge

Industrial teams still hold years of ops data in Wonderware Historian (AVEVA Historian). As analytics and cloud needs grow, they need a scalable, cost-efficient path to modern TSDB storage — without ripping out the plant overnight.

## What I published

[Ingest Data from Wonderware Historian](https://tdengine.com/ingest-data-from-wonderware-historian/) on tdengine.com — a step-by-step guide to:

- Add an **AVEVA Historian** source in TDengine TSDB-Explorer (**Data In**)
- Connect via SQL Server hostname/port and authenticate
- Choose **migrate** or **synchronize** (historical `Runtime.dbo.History` or live `Runtime.dbo.Live`)
- Configure tags, time windows, retrieve intervals, and tolerance
- Map columns into TDengine supertables, preview, and submit the ingestion task

## Outcome

A public enablement artifact for Wonderware → TDengine modernization — migrate, sync history, or keep real-time flowing — so customers can modernize architecture without disrupting existing operations.
